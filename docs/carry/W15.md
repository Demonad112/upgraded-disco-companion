## Method
- Build: `npm run build` (static export), served locally by a copy of `e2e/serve.mjs`.
- Trace: Playwright + CDP, home page, 1.5 s settle, `Emulation.setCPUThrottlingRate` 4, 10 s Chrome trace
  (`devtools.timeline`, `toplevel`).
- **draw** = `FireAnimationFrame` on the renderer main thread (the sky's own JS).
- **frame** = all main-thread `RunTask` time between one sky draw and the next (draw, paint, commit; in this container the
  canvas is software-rastered during commit, so this is where the sky's pixel cost lands). This is the budget metric.
- **viz** = the same window on the display compositor thread (software compositing here; on a real GPU this is the GPU's job).
- Absolute numbers overstate a real device: the cloud container has no GPU, so canvas raster and compositing run on CPU.
  Use them as relative numbers between builds on the same machine.
- Throttled, the main thread is ~87 % busy, so the 30 fps cap is never reached; achieved fps is listed for that reason.

this GPU-less container.
